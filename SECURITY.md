# Security policy

**Copyright © 2026 Olivier RENAULT — Apache-2.0**


Please do not publish credentials, private repository tokens, proxy passwords, certificates containing private keys, or other secrets in public issues.

For security-sensitive reports, use the repository's private security reporting feature when enabled.

RFPY executes package-manager and installer operations requested by the user. Review configured package indexes and trust roots before installing packages from private or third-party repositories.
